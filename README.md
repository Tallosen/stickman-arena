## Проверка на телефоне

Открой игровую ссылку в обычном браузере. Проверь касания, поворот экрана, звук после сворачивания, подбор награды босса, смерть и финал. Дойди до следующей стадии, обнови страницу и выбери «Продолжить»: должны восстановиться герой, оружие, питомец и счёт. При закрытии возвращается последняя записанная контрольная точка. Прогресс разных браузеров и устройств автоматически не объединяется.

## Разработка

Нужен Node.js 22 или новее. `npm ci` устанавливает зависимость Canvas для автоматических проверок. Затем:

```sh
npm run build
npm test
npm run preflight
```

Игра написана на JavaScript и Canvas без игрового движка. Корневой `index.html` — шаблон с подключением `src/`; не заменяй его готовым HTML из `dist`, иначе повторная сборка продублирует код. GitHub Pages использует `main` и корень репозитория.

- `dist/index.html` — обычная самостоятельная сборка.
- `dist/StickmanArena_v0.208_QA.html` — версия с админ-панелью и отдельными тестовыми сохранениями.
- `dist/playgama/` — файлы для QA Tool Playgama; этот вариант требует среды платформы.
- `assets/audio/`, `AUDIO_CREDITS.md` — используемые звуки и сведения об их происхождении. Присланные пользователем MP3-референсы сюда не включены.
- `audit/weapon-preview-v0173.wav` — звуковая контрольная запись, которую использует один из тестов.

## Проверки и статус

В 0.208 проходят 94 набора автоматических проверок, включая повторный запуск HTML с синтетическими сохранениями. Они не заменяют прохождение на настоящем телефоне и в Playgama. Текущие результаты находятся в `audit/regression-current.json` и `audit/release-preflight.json`; `publishReady` остаётся `false` до завершения внешних проверок.

Сохранения читаются до начала игры. Награды и соответствующая контрольная точка записываются совместно. Неизвестные форматы сохраняются без перезаписи. Победа и поражение закрывают забег. Исторические сведения о старой коллекции драконов в CHANGELOG относятся к прежним версиям.
