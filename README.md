## Как запускать
Открыть `index.html` в браузере. Ничего ставить не нужно, зависимостей нет.

## Как публиковать
```
node build.js
```
Соберёт `dist/index.html` — один самодостаточный файл. Его и заливать
на GitHub Pages или отдавать паблишеру для Playables.

## Модули

| Файл | За что отвечает |
|---|---|
| `src/core.js` | канвас, размеры экрана, карандашные линии, звук |
| `src/config.js` | все константы: одежда, оружие, питомцы, перки, предметы |
| `src/pets.js` | поведение шести питомцев, яйца и цыплята |
| `src/draw-pets.js` | как питомцы, яйца, цыплята, турели и предметы выглядят |
| `src/state.js` | состояние игрока, ввод, пауза, пересчёт характеристик |
| `src/world.js` | враги, взрывы, сундуки, бусты, столкновения с камнями |
| `src/abilities.js` | постоянный инвентарь, авиаудар, химический дым и разрушаемый союзный танк |
| `src/update.js` | главный цикл: движение, стрельба, урон, подбор |
| `src/cards.js` | окна выбора на новой стадии и после смерти |
| `src/draw-hero.js` | модели оружия и послойная одежда героя |
| `src/draw-foe.js` | враги и анимации смерти |
| `src/render.js` | сборка кадра целиком |
| `src/ui.js` | интерфейс, радар, кружок питомца, кнопки |

## Куда лезть за типовой правкой

- **баланс чисел** → `config.js` и `petStats()` в `pets.js`
- **новая вещь или оружие** → `config.js` + `applyGear()` в `state.js` + `draw-hero.js`
- **новый питомец** → `config.js` + `updatePet()` в `pets.js` + `drawPet()` в `draw-pets.js`
- **новый враг** → `KINDS` в `world.js` + `drawFoe()` в `draw-foe.js`
- **интерфейс** → `ui.js`

## Редкий сундук

При каждой попытке появления сундука шанс редкой версии равен 3.5%. Она открывается
сразу при подборе и случайно выдаёт один заряд из трёх способностей. Заряды хранятся
в `localStorage` под ключом `vacky_stickman_inventory_v1`.
