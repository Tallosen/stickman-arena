# Stickman Arena — Vacky Games

## Дом драконов — 0.62

- В книге 3 дракона одной редкости обмениваются на одного следующей: зелёный → синий → фиолетовый → розовый → чёрно-золотой → золотой → бриллиантовый. Обмен расходует коллекцию, но не историю спасений.
- Дом доступен из главного меню, паузы, книги, итогов забега и кнопкой ⌂ рядом с книгой.
- Выбери одну из трёх оболочек яйца. Каждый вклад расходует одного бриллиантового дракона. Всего нужно 5, ожидания по часам нет. Прогресс сохраняется после каждого вклада. После первого вклада смена яйца запрещена.
- На пятом вложении заранее сохраняется случайный результат, затем проигрывается вылупление. Если закрыть дом или перезагрузить игру во время анимации, готовое яйцо можно вылупить позже без повторного списания и переброса результата.
- 100 процедурно спроектированных low-poly 3D-моделей: 10 анатомических семейств × 10 вариантов геометрии и окраски. Виверны, змеи, бастионы, серафимы, гидры, кристаллические, морские, пернатые, ночные и астральные драконы имеют разные крылья, пропорции, хвосты и украшения. Это настоящая полигональная геометрия с перспективой и освещением, без внешних библиотек.
- Все 100 результатов равновероятны (1% каждый), оболочка яйца не меняет шанс. Повторы накапливаются отдельным счётчиком. В интерфейсе неизвестные модели, названия и силуэты не раскрываются; клиентский исходный код, конечно, не является секретным сервером.
- Хранилище: вращение пальцем/мышью, наклон, масштаб двумя пальцами/колесом/кнопками, автоматическая демонстрация, анимированные крылья и эффекты. Рендер ограничен 30 кадрами/с и останавливается при закрытом доме/скрытой вкладке.
- Сохранение `vacky_dragon_home_v2` объединяет коллекцию, историю спасений, яйцо и эксклюзивов. Старая `vacky_stickman_dragons_v1` автоматически читается при первом запуске и не удаляется. Не переносите обратно старую версию после начала крафта: она не знает про новый кошелёк.
- Прогресс локальный: сохраняется на том же адресе в том же браузере. Нет аккаунта, облачной синхронизации и защиты от редактирования сохранений. GitHub Pages и локальный HTML имеют разные хранилища; очистка данных сайта удаляет прогресс.

Для GitHub Pages публикуй `index.html` и всю папку `src` вместе. Альтернатива — содержимое `dist` как единый HTML. Не смешивай модули разных версий. Сборка: `node build.js`.

## Версия

Живёт в `src/config.js`, константа `VERSION`. Оттуда сама попадает
в заголовок вкладки, на стартовый экран и в имя собранного файла.
При правках поднимать её там.

## Как запускать
Открыть `index.html` в браузере. Ничего ставить не нужно, зависимостей нет.

## Как публиковать
```
node build.js
```
Соберёт `dist/index.html` — один самодостаточный файл. Его и заливать
на GitHub Pages или отдавать паблишеру для Playables.

## Модули

| Файл | За что отвечает |
|---|---|
| `src/core.js` | канвас, размеры экрана, карандашные линии, звук |
| `src/config.js` | все константы: одежда, оружие, питомцы, перки, предметы |
| `src/pets.js` | поведение шести питомцев, яйца и цыплята |
| `src/draw-pets.js` | как питомцы, яйца, цыплята, турели и предметы выглядят |
| `src/state.js` | состояние игрока, ввод, пауза, пересчёт характеристик |
| `src/world.js` | враги, взрывы, сундуки, бусты, столкновения с камнями |
| `src/abilities.js` | постоянный инвентарь, авиаудар, химический дым и разрушаемый союзный танк |
| `src/dragons.js` | финальная осада, анимации семи драконов, сохранение коллекции и книга достижений |
| `src/dragon-economy.js` | миграция сохранений, кошелёк, крафт 3→1 и атомарные операции с яйцом |
| `src/dragon-3d.js` | 100 объёмных моделей, геометрия, перспектива, освещение и эффекты |
| `src/dragon-home.js` | дом, инкубатор, хранилище, вылупление и управление 3D-просмотром |
| `src/update.js` | главный цикл: движение, стрельба, урон, подбор |
| `src/cards.js` | окна выбора на новой стадии и после смерти |
| `src/draw-hero.js` | модели оружия и послойная одежда героя |
| `src/draw-foe.js` | враги и анимации смерти |
| `src/render.js` | сборка кадра целиком |
| `src/ui.js` | интерфейс, радар, кружок питомца, кнопки |

## Куда лезть за типовой правкой

- **баланс чисел** → `config.js` и `petStats()` в `pets.js`
- **новая вещь или оружие** → `config.js` + `applyGear()` в `state.js` + `draw-hero.js`
- **новый питомец** → `config.js` + `updatePet()` в `pets.js` + `drawPet()` в `draw-pets.js`
- **новый враг** → `KINDS` в `world.js` + `drawFoe()` в `draw-foe.js`
- **интерфейс** → `ui.js`

## Перед релизом
Проверка новой экономики и геометрии: `node tests/dragon-home.test.cjs` (сначала `node build.js`).

Удалить тестовые кнопки `+STAGE`, `+ULT`, `+RARE`, `+SNP`, `+FULL` и `+DRG`: теги `#devLvl`, `#devUlt`, `#devRare`, `#devSniper`, `#devFull`, `#devDragon`
в `index.html`, блок `.hud-dev` в стилях и обработчики в `ui.js`.

## Редкий сундук

При каждой попытке появления сундука шанс редкой версии равен 3.5%. Она открывается
сразу при подборе и случайно выдаёт один заряд из трёх способностей. Заряды хранятся
в `localStorage` под ключом `vacky_stickman_inventory_v1`.
