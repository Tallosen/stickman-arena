# v0.155 — запуск арены и YouTube Playables

## Какой файл использовать

- `dist/index.html` — обычная игра для локального запуска и GitHub Pages. Можно выложить его как корневой `index.html`, остальные файлы для этой сборки не нужны.
- Исходный `index.html` вместе с папкой `src/` — модульная версия для разработки. `node build.js` обновляет собранные файлы.
- `dist/youtube/index.html` — строгая сборка для Playables/Test Suite. При отсутствии настоящей среды SDK она показывает пояснение и не переключается на локальное сохранение.
- `VackyGames_StickmanArena_v0.155_YOUTUBE.zip` содержит строгий `index.html` непосредственно в корне. Это пакет для проверки, не подтверждение публикации.

Коллекция, крафт и инкубатор удалены из арены. Концепт и рабочая версия 0.123 сохранены отдельно; их старые данные в контейнере остаются нетронутыми.

## Что реализовано

Официальный SDK подключён в начале HTML. Модули выполняются после успешного чтения прогресса. `firstFrameReady()` вызывается на экране загрузки, `gameReady()` — после первого игрового кадра и открытия взаимодействия. Основа интеграции сверена с [официальным руководством](https://developers.google.com/youtube/gaming/playables/reference/getting_started).

`onPause/onResume` останавливают и возвращают игровой цикл, ввод, отложенные эффекты, анимацию стартового лагеря и звук. Время паузы не прибавляется к стадиям и анимации меню. Ручная пауза игрока после возобновления YouTube сохраняется. В среде Playables нет обработчиков Page Visibility; вне неё прежняя браузерная пауза сохранена. Звук управляется настройкой SDK и общим аудиоканалом игры.

Чтение выполняется до записи. Записи сериализуются: одновременно отправляется один снимок, следующие изменения отправляются после него. До подтверждения игра закрыта блокирующим экраном. При ошибке отправки остаётся кнопка повтора; неподтверждённые изменения находятся только в памяти, поэтому нельзя закрывать или перезагружать игру до успешной отправки. При ошибке чтения или неизвестном формате запуск блокируется без перезаписи. Эти решения учитывают [требования интеграции](https://developers.google.com/youtube/gaming/playables/certification/requirements_integration).

## Формат и границы сохранений

Облачный контейнер: `{format:"vacky-playables", version:1, records:{...}}`. Значения records — JSON-строки существующих доменных профилей:

- `vacky_dragon_home_v2`: архивный профиль драконов. Арена его не изменяет, но сохраняет при обновлении общего контейнера.
- `vacky_stickman_inventory_v1`: постоянные заряды способностей.
- `vacky_meta_v1`: постоянные улучшения и рекорд времени.
- `vacky_stickman_dragons_v1`: старый формат коллекции, если присутствует в снимке.

Поддерживается также облачная запись в виде отдельного профиля драконов версии 2. Неизвестные строковые ключи сохраняются при обновлениях; повреждённые известные данные и неизвестная версия контейнера блокируют запуск. Размер нового снимка ограничен консервативной оценкой 60 000 байт.

Локальные ключи старых версий не меняются. В YouTube они не читаются и не импортируются автоматически: облачный и GitHub-профили независимы. Публичного облачного формата до этой интеграции не было. С 0.206 здоровье, позиция, стадия, оружие и остальной прогресс забега сохраняются контрольными точками вместе с постоянным профилем. После перезагрузки доступно продолжение с последней подтверждённой точки; живую проверку хранилища платформы ещё предстоит выполнить.

## Проверки перед отправкой

Локально: `node tests/run-arena.cjs`. Этот актуальный набор включает полный HTML с имитацией DOM/SDK в локальном, YouTube и Playgama-режимах. Тесты не обращаются к аккаунтам площадок. Нативный Canvas-предпросмотр проверяется отдельно; настоящий браузер/телефон не проверялся.

Официальный [Test Suite](https://developers.google.com/youtube/gaming/playables/reference/test_suite_guide) ещё не запускался. Перед публикацией необходимо проверить в нём строгую сборку, включая CSP, первый запуск без данных, повторный вход со старым профилем, отказ сети при сохранении, паузу во время загрузки/боя/анимации меню, выключенный звук и реальные телефонные касания. Затем требуется отдельная проверка остальных условий публикации и локализации. Реклама и отправка результатов в таблицу YouTube в эту версию не добавлены.

Интеграция не публикует игру, не переносит аккаунты и не означает одобрения YouTube.
