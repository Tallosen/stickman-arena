# v0.94 — запуск, коллекция и YouTube Playables

## Какой файл использовать

- `dist/index.html` — обычная игра для локального запуска и GitHub Pages. Можно выложить его как корневой `index.html`, остальные файлы для этой сборки не нужны.
- Исходный `index.html` вместе с папкой `src/` — модульная версия для разработки. `node build.js` обновляет собранные файлы.
- `dist/youtube/index.html` — строгая сборка для Playables/Test Suite. При отсутствии настоящей среды SDK она показывает пояснение и не переключается на локальное сохранение.
- `VackyGames_StickmanArena_v0.94_YOUTUBE.zip` содержит строгий `index.html` непосредственно в корне. Это пакет для проверки, не подтверждение публикации.
- `dist/DragonCatalog_v0.94.html` — локальный административный просмотр моделей, не файл для публикации в YouTube.

Разделение экранов Дома — наше интерфейсное решение, а не требование SDK. Оба раздела остаются внутри одной игры и используют один профиль.

## Что реализовано

Официальный SDK подключён в начале HTML. Модули выполняются после успешного чтения прогресса. `firstFrameReady()` вызывается на экране загрузки, `gameReady()` — после первого игрового кадра и открытия взаимодействия. Основа интеграции сверена с [официальным руководством](https://developers.google.com/youtube/gaming/playables/reference/getting_started).

`onPause/onResume` останавливают и возвращают игровой цикл, ввод, отложенные эффекты, пещеру и звук. Время паузы не прибавляется к стадиям, вылуплению и анимации осмотра. Ручная пауза игрока после возобновления YouTube сохраняется. В среде Playables нет обработчиков Page Visibility; вне неё прежняя браузерная пауза сохранена. Звук управляется настройкой SDK и общим аудиоканалом игры.

Чтение выполняется до записи. Записи сериализуются: одновременно отправляется один снимок, следующие изменения отправляются после него. До подтверждения игра закрыта блокирующим экраном. При ошибке отправки остаётся кнопка повтора; неподтверждённые изменения находятся только в памяти, поэтому нельзя закрывать или перезагружать игру до успешной отправки. При ошибке чтения или неизвестном формате запуск блокируется без перезаписи. Эти решения учитывают [требования интеграции](https://developers.google.com/youtube/gaming/playables/certification/requirements_integration).

## Формат и границы сохранений

Облачный контейнер: `{format:"vacky-playables", version:1, records:{...}}`. Значения records — JSON-строки существующих доменных профилей:

- `vacky_dragon_home_v2`: драконы, история спасений, эксклюзивы, яйцо и заранее выбранный результат вылупления.
- `vacky_stickman_inventory_v1`: постоянные заряды способностей.
- `vacky_meta_v1`: постоянные улучшения и рекорд времени.
- `vacky_stickman_dragons_v1`: старый формат коллекции, если присутствует в снимке.

Поддерживается также облачная запись в виде отдельного профиля драконов версии 2. Неизвестные строковые ключи сохраняются при обновлениях; повреждённые известные данные и неизвестная версия контейнера блокируют запуск. Размер нового снимка ограничен консервативной оценкой 60 000 байт.

Локальные ключи старых версий не меняются. В YouTube они не читаются и не импортируются автоматически: облачный и GitHub-профили независимы. Публичного облачного формата до этой интеграции не было. Здоровье, позиция, стадия и оружие незавершённого забега не сохраняются между открытиями игры — сохранение постоянной коллекции не является контрольной точкой боя.

## Проверки перед отправкой

Локально: `node tests/playables.test.cjs` и `node tests/playables-bundle.test.cjs`. В PowerShell весь набор: `node --test (Get-ChildItem tests/*.test.cjs | ForEach-Object { $_.FullName })`. Тесты не обращаются к аккаунту YouTube. Полный HTML проверяется с имитацией DOM/SDK; WebGL в этом тесте намеренно отсутствует, поэтому используется резервная отрисовка.

Официальный [Test Suite](https://developers.google.com/youtube/gaming/playables/reference/test_suite_guide) ещё не запускался. Перед публикацией необходимо проверить в нём строгую сборку, включая CSP, первый запуск без данных, повторный вход с коллекцией, отказ сети при крафте/инкубации, паузу во время загрузки/боя/вылупления, выключенный звук и реальные телефонные касания. Затем требуется отдельная проверка остальных условий публикации и локализации. Реклама и отправка результатов в таблицу YouTube в эту версию не добавлены.

Интеграция не публикует игру, не переносит аккаунты и не означает одобрения YouTube.
